# Currículum Vitae / Catalina González
Este proyecto es una web diseñada a través de HTML y CSS para presentar mi currículum vitae.

## Especificaciones de maquetación
-Como editor de código utilicé Visual Studio Code

-La pantalla en la que trabajé es un monitor de 15.6 pulgadas

-El ancho contenedor de diseño lo estandaricé a un ancho máximo de 1200px

-Para la tipografía utilicé la familia tipográfica Montserrat, en sus variantes: Regular, SemiBold y Bold para establecer jerarquias

-Uso de contenedores sólidos y centralizados

-Uso de Flexbox en secciones estratégicas 

## Estructura del repositorio:
index.html: Estructura principal de la página

estilos.css: Hoja de estilos donde se marcan las necesidades estéticas de la página 

fonts: Archivos ttf (Montserrat)

img: Recursos gráficos utilizados en la página
